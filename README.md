# 🌐 Personal Portfolio Website

A modern, responsive personal portfolio website showcasing my skills, projects, experience, education, and contact information.

The website is designed to provide a clean and interactive way to learn more about me, explore my technical work, and get in touch.

## ✨ Features

* 📱 Fully responsive design
* 👨‍💻 About Me section
* 🛠️ Skills and technologies
* 🚀 Projects showcase
* 🎓 Education section
* 💼 Experience section
* 📄 Resume/CV section
* 📬 Contact section
* 🔗 Social media and professional profile links
* ⚡ Fast and user-friendly interface
* 🎨 Modern and clean UI

## 🛠️ Tech Stack

The website is built using:

* **Frontend :** `HTML / CSS / JavaScript`
* **Styling :** `CSS / Tailwind CSS`
* **Deployment :** `Netlify`
